# 大屏验收细目

按项目风险选择检查项，不要求每个原型都实现全部特效。

| 维度 | 检查问题 |
| --- | --- |
| 一眼可读 | 在目标观看距离，主标题、关键值、异常和下一步动作是否可辨？信息是否按业务重要性排序？ |
| 口径 | 每个指标是否有单位、统计范围、时间窗、更新时间和来源类型？数值、图例、轴及 tooltip 是否一致？ |
| 布局 | 目标屏幕、1920×1080、1366 宽及任务指定比例有无滚动、遮挡、过小文字和图表裁切？ |
| 场景 | 3D/地图是否对应真实业务空间、模型或地理数据？是否有版权、坐标、比例和命名依据？ |
| 交互 | 选中、下钻、筛选、时间切换、返回、主题切换后，场景、面板和图表是否保持同一状态？ |
| 动效 | 入场、数字变化、告警和巡游是否有明确用途？暂停、隐藏页、减少动态效果设置是否有效？ |
| 异常 | 空数据、过期数据、加载失败、网络断开、WebGL 不可用时是否明确提示并保持基本可用？ |
| 性能 | 重复进入、窗口缩放、长时间展示后是否正常；材质/纹理/监听器是否释放，帧率和内存是否符合目标设备？ |
| 真实性 | 演示数据、手填数据和实时接口是否明确区分；尚无真实数据的画面是否避免写成实时监控或数字孪生？ |

当数据、模型或运行设备不可得时，记录未验收项及需要的证据，不以文件存在或静态截图代替通过。
