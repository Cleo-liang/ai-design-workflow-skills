# 组件与页面状态检查

从业务流程选择需要的项目，并为每个组件记录用途、尺寸、变体、状态、键盘行为、禁用条件、错误文案及对应 token。

| 组别 | 常见内容 | 容易遗漏的状态 |
| --- | --- | --- |
| 操作与输入 | 按钮、链接、输入框、搜索、选择器、复选/单选、开关、日期、上传 | 聚焦、禁用、加载、校验、清空、撤销 |
| 导航 | 侧边栏、顶部导航、面包屑、标签页、步骤条、分页 | 当前项、返回路径、溢出、权限不可见 |
| 数据 | 表格、卡片、图表、树、详情字段、筛选器 | 空、加载、部分数据、排序、批量选择、长内容 |
| 反馈与弹层 | 提示、告警、气泡确认、抽屉、弹窗、通知 | 焦点管理、关闭、取消、错误恢复、危险操作确认 |

页面模板至少覆盖一个关键任务的完整路径。列表页要核筛选与分页是否保持状态；表单页要核草稿、错误定位和提交反馈；详情页要核权限及返回；工作台要核指标来源和跳转。移动端还需在实际设备尺寸检查触控目标、软键盘、底部安全区和横竖屏。
