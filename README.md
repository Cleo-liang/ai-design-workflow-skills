# AI Design Workflow Skills

面向 Codex 的三个中文设计 skill：

| Skill | 适用任务 | 主要产物 |
| --- | --- | --- |
| [ai-dashboard-design](ai-dashboard-design/SKILL.md) | 数据可视化大屏、展厅总览、需要空间主视觉的监控界面 | 信息架构、数据口径、视觉方案、可运行大屏、实屏验收 |
| [software-ui-design-system](software-ui-design-system/SKILL.md) | PC 管理系统、移动应用、跨页面设计规范与组件库 | 设计变量、组件状态、页面模板、交互与开发规范 |
| [visual-to-code-handoff](visual-to-code-handoff/SKILL.md) | 将图片或设计稿转成可维护、可交互的前端 | 资源清单、组件化代码、视觉对照和功能验证 |

直接在任务中指定 `$ai-dashboard-design` 等名称，或读取对应 `SKILL.md`。三个 skill 不绑定某个生图平台、模型、Figma 插件或前端框架；已有项目应优先沿用自己的技术栈和设计系统。

## 提炼依据

方法受宋夏天 Dazzle 的 AI 设计教程启发，结合真实项目交付需要重新整理。重点参考其大屏概念图到 Figma/代码、3D 场景、组件库与变量、设计稿反推规范、图转可编辑 UI 的流程。来源和取舍见 [研究摘要](RESEARCH.md)。本仓库没有收录原教程、截图、素材、插件或原文提示词，也不代表原作者认可或参与本仓库。
